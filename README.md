# Vinothek Steinfurt — Dawn Theme Mockup

Statisches HTML/CSS-Mockup basierend auf der Shopify Dawn-Sektionsstruktur, gestylt mit dem
Vinothek-Steinfurt-Design-System (Bordeaux/Terrakotta/Gold, Cormorant Garamond + Hanken Grotesk).

## Struktur
- `index.html` — vollständiges Ein-Datei-Mockup (Announcement Bar, Header, Hero, Featured Collection,
  Story, Turmwächter-Spotlight, Events, Features, Reservierung, Newsletter, Footer, Age-Gate)

Jede Section ist im Code kommentiert mit dem passenden Dawn-Liquid-File
(z. B. `sections/hero.liquid`, `sections/featured-collection.liquid`) für die 1:1-Übernahme
ins echte Shopify-Theme.

## Design-Tokens
Siehe CSS `:root` in `index.html` — Farben, Typografie und Spacing sind direkt aus dem
Vinothek-Steinfurt-Design-System übernommen und Webflow/Shopify-kompatibel benannt
(`--color-primary-wine`, `--color-terracotta`, `--color-gold` usw.).
